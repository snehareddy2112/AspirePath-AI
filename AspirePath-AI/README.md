# AspirePath AI - Application Source

This directory contains the core fullstack source code for **AspirePath AI**.

## Directory Layout

```
AspirePath-AI/
├── Client/     # React 18 + TypeScript + Vite frontend SPA
└── Server/     # Node.js + Express API backend service
```

## Quick Start

### 1. Backend
```bash
cd Server
npm install
npm run dev
```

### 2. Frontend
```bash
cd Client
npm install
npm run dev
```

For full setup details, environment configuration, and deployment guides, please refer to the [Root README.md](../README.md).
